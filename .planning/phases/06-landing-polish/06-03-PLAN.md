# Plan 06-03: Read-Only Schema Graph Demo

**Phase:** 6 — Landing Polish
**Wave:** 3 (independent — no deps on 06-01/06-02)
**Requirements:** LGRAPH-01, LGRAPH-02

## Goal

Embed an interactive read-only sample ER diagram (ReactFlow + dagre) in the landing page that loads instantly from bundled static data.

## Files

| Action | File                                           |
| ------ | ---------------------------------------------- |
| Edit   | `landing/package.json` (add deps)              |
| Create | `landing/src/lib/sample-schema.ts`             |
| Create | `landing/src/components/schema-graph-demo.tsx` |
| Edit   | `landing/src/components/home-view.tsx`         |

## Steps

1. **Install dependencies** in landing:
   - `npm --prefix landing install @xyflow/react dagre`
   - `npm --prefix landing install -D @types/dagre`
   - This adds the same ReactFlow + dagre packages used by the desktop app.
2. **Create `landing/src/lib/sample-schema.ts`** — bundled static sample schema:
   - Export `SampleTable` type: `{ name, schema?, columns: { name, type, primaryKey, foreignKey? }[] }`
   - Export `SAMPLE_SCHEMA: { tables: SampleTable[] }` — a small e-commerce schema with 5 tables:
     - `users` (id PK, email, name, created_at)
     - `products` (id PK, name, price, category_id FK→categories)
     - `categories` (id PK, name, parent_id FK→categories self-ref)
     - `orders` (id PK, user_id FK→users, total, created_at)
     - `reviews` (id PK, product_id FK→products, user_id FK→users, rating, comment)
   - No API call needed — loads instantly.
3. **Create `landing/src/components/schema-graph-demo.tsx`** — client component:
   - Reuse the dagre layout pattern from `apps/desktop/src/components/schema-graph.tsx`:
     - `buildGraph(data)` → nodes/edges via dagre (rankdir: LR, nodesep, ranksep).
     - `TableNode` component renders a card with column list, PK/FK indicators.
   - ReactFlow with `Background`, `Controls`, `MiniMap`.
   - Read-only: `nodesConnectable={false}`, `edgesFocusable={false}`. Nodes remain draggable (visitors can rearrange) but cannot create edges.
   - No `onNodeClick` (no tab opening — this is a demo, not the app).
   - Themed to match landing dark/light mode using CSS variables from `globals.css`.
   - `fitView` on mount so all tables are visible.
4. **Edit `landing/src/components/home-view.tsx`** — insert schema graph demo section:
   - Import `SchemaGraphDemo` from `./schema-graph-demo`.
   - Place between "Features" section and "Install" section.
   - Add `SectionHeading` with title "See your schema, visualized" and subtitle "Interactive ER diagram from bundled sample data — no connection needed."
   - Wrap the demo in a themed container with border and shadow matching existing sections.
5. **Verify:** `npm --prefix landing run build` passes.

## Verify Gate

- `npm --prefix landing run build` green
- Schema graph demo renders 5 tables with FK edges
- Graph loads instantly (no API call, no loading spinner)
- Nodes are draggable but edges cannot be created (read-only)
- dagre layout positions tables in a left-to-right hierarchy
