# Plan 06-02: Screenshot Refresh CI Workflow

**Phase:** 6 — Landing Polish
**Wave:** 2 (independent — no deps on 06-01/06-03)
**Requirements:** LCI-01, LCI-02

## Goal

Create a Playwright-based screenshot capture script and a GitHub Actions workflow that runs on every release tag, captures fresh AI Compare panel screenshots, and commits them back to the repo.

## Files

| Action | File                                       |
| ------ | ------------------------------------------ |
| Create | `landing/scripts/capture-images.mjs`       |
| Create | `.github/workflows/screenshot-refresh.yml` |

## Steps

1. **Create `landing/scripts/capture-images.mjs`** — Playwright capture script:
   - Start the Next.js dev server (`next dev`) on a fixed port (3210) as a child process.
   - Wait for the server to be ready (poll `http://localhost:3210`).
   - Launch Playwright Chromium, navigate to `http://localhost:3210`.
   - Wait for the AI Compare section to render (selector-based wait).
   - Screenshot the chat panel area → `landing/public/images/chat-panel.png`.
   - Screenshot the SQL panel area → `landing/public/images/sql-panel.png`.
   - Close browser, kill dev server, exit 0.
   - Script is idempotent and runnable locally: `node landing/scripts/capture-images.mjs`.
   - Uses ESM (`import` syntax, `.mjs` extension). No new npm dependencies (Playwright already in devDependencies).
2. **Create `.github/workflows/screenshot-refresh.yml`** — CI workflow:
   - Triggers: `push` on tags matching `v*`, plus `workflow_dispatch`.
   - Permissions: `contents: write` (needed to commit back).
   - Steps: checkout, setup Node 22, `npm --prefix landing install`, install Playwright browsers (`npx playwright install chromium`), run capture script, commit updated images using `stefanzweifel/git-auto-commit-action@v5` with message `chore: refresh AI Compare screenshots [skip ci]`.
   - Commit only `landing/public/images/*.png` files.
3. **Verify:** Workflow file is valid YAML. Script has no syntax errors (`node --check`).

## Verify Gate

- `node --check landing/scripts/capture-images.mjs` passes
- `.github/workflows/screenshot-refresh.yml` is valid YAML
- Workflow triggers on `v*` tags
- Workflow commits updated images back to the repo
