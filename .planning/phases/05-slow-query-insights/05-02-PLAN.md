# Plan 05-02: p95 Aggregation + Slow Queries View

**Phase:** 5 — Slow-Query Insights
**Wave:** 2 (depends on 05-01 — uses `normalizeQuery` + `computeP95` from lib)
**Requirement:** SLOWQ-01 (Slow queries view, top-N by p95)

## Goal

Add a two-tab layout to `QueryHistoryPanel`: "History" (existing) and "Slow queries" (new). The Slow queries tab groups entries by normalized pattern, computes p95 per group, sorts descending by p95, and shows the top-N rows.

## Files

| Action | File                                                           |
| ------ | -------------------------------------------------------------- |
| Edit   | `apps/desktop/src/components/query-history-panel.tsx`          |
| Edit   | `apps/desktop/src/lib/constants.ts` (add `TOP_N_SLOW_QUERIES`) |

## Steps

1. **Add constant** to `apps/desktop/src/lib/constants.ts`:
   - `export const TOP_N_SLOW_QUERIES = 10;`
2. **Edit `query-history-panel.tsx`**:
   - Import `Tabs, TabsList, TabsTrigger, TabsContent` from `@/components/ui/tabs`.
   - Import `computeP95` from `@/lib/query-normalize`, `TOP_N_SLOW_QUERIES` from `@/lib/constants`.
   - Extend `PatternGroup` type with `p95: number | null` and `durations: number[]`.
   - In the `groups` useMemo: collect `durations` (filter `durationMs` defined), compute `p95` via `computeP95`.
   - Add a `slowGroups` useMemo: filter groups with `p95 !== null`, sort by `p95` descending, slice `TOP_N_SLOW_QUERIES`.
   - Add a `tab` state: `useState<'history' | 'slow'>('history')`.
   - Wrap the list section in `<Tabs value={tab} onValueChange={setTab}>` with a `TabsList` (two triggers) placed below the search box. `TabsContent value="history"` renders the existing `filtered` list; `TabsContent value="slow"` renders the `slowGroups` list.
   - Slow-query row: normalized pattern (mono, line-clamp-2), p95 badge (`{p95}ms p95`), count (`{count}x`), recent raw query preview (truncated). Clicking the row calls `onSelectQuery(lastEntry.query)`.
   - Empty state for slow tab: "No slow queries yet" / "No queries with duration data".
3. **Verify:** `pnpm -r typecheck` passes; manual render sanity (the panel mounts under the SQL editor).

## Verify Gate

- `pnpm -r typecheck` green
- Slow queries tab renders top-N by p95 descending
- History tab unchanged behavior
