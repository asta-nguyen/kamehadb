# Plan 05-03: Wire AI Pre-Seed from Slow Query

**Phase:** 5 — Slow-Query Insights
**Wave:** 3 (depends on 05-02 — adds buttons to the slow-query rows)
**Requirement:** SLOWQ-03 (pre-seed AI chat from a slow query)

## Goal

Add "Suggest index" and "Explain" action buttons to each slow-query row. Both reuse the Phase 4 `setPendingAiPrompt` + `openAiChatPanel` store flow to pre-seed the AI chat panel with a prompt grounded in the slow query's normalized pattern, sample raw SQL, p95, and call count.

## Files

| Action | File                                                                 |
| ------ | -------------------------------------------------------------------- |
| Edit   | `apps/desktop/src/lib/constants.ts` (add `SLOW_QUERY_AI_ACTIONS`)    |
| Edit   | `apps/desktop/src/components/query-history-panel.tsx` (wire buttons) |

## Steps

1. **Add slow-query AI action templates** to `apps/desktop/src/lib/constants.ts`:
   - `SLOW_QUERY_AI_ACTIONS` record with two keys `'suggest-index'` and `'explain'`, each `{ label, icon, buildPrompt(ctx) }` where `ctx = { pattern, sampleQuery, p95, count }`.
   - `suggest-index` prompt: "Suggest indexes to speed up this slow query (p95 {p95}ms, run {count} times):\n\n`\n{sampleQuery}\n`\n\nExplain the rationale and provide CREATE INDEX statements."
   - `explain` prompt: "Explain why this query is slow (p95 {p95}ms, run {count} times) and suggest optimizations:\n\n`\n{sampleQuery}\n`"
   - Icons: `KeyRound` (suggest-index), `Sparkles` (explain) — already imported in constants.ts.
2. **Edit `query-history-panel.tsx`**:
   - Import `openAiChatPanel, setPendingAiPrompt` from `@/store`.
   - Import `SLOW_QUERY_AI_ACTIONS` from `@/lib/constants`.
   - Add a `handleSlowQueryAiAction(group, action)` handler:
     - `openAiChatPanel(connectionId)`
     - `setPendingAiPrompt({ prompt: SLOW_QUERY_AI_ACTIONS[action].buildPrompt({ pattern, sampleQuery: lastEntry.query, p95, count }) })` — no `tableId` (not table-scoped).
   - Render two `Button` (ghost, icon size-5) per slow-query row, visible on hover (`opacity-0 group-hover:opacity-100`), with `KeyRound` and `Sparkles` icons and titles "Suggest index" / "Explain".
3. **Verify:** `pnpm -r typecheck` passes; `pnpm --filter @kamehadb/desktop test` passes.

## Verify Gate

- `pnpm -r typecheck` green
- `pnpm --filter @kamehadb/desktop test` green
- Clicking "Suggest index" on a slow row opens AI panel + queues the prompt (reuses Phase 4 flow)
