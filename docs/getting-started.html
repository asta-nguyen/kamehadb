Getting Started

KamehaDB is a cross-platform database GUI with built-in AI. Follow this guide to set up and run it in minutes.

Prerequisites

  • Node.js 20+
  • pnpm 9+
  • Docker (for dev databases)
  • Rust (for Tauri desktop app)

Installation

git clone https://github.com/asta-nguyen/kamehadb.git
cd kamehadb
pnpm install

Start Dev Databases

docker compose up -d
Default credentials:
EnginePortUserPasswordDatabase
PostgreSQL5432kamehakamehakamehadb

Run the App

# Start both sidecar (backend) and desktop (frontend)
pnpm dev

Building for Production

# Build all packages
pnpm build

# Build Tauri desktop app
pnpm tauri build
