Getting Started

Install dependencies, start dev services, and launch the desktop app in a few minutes.

Prerequisites

Node.js

v20+

pnpm

v9+

Docker

for dev databases

Rust

for Tauri build

1. Clone and install

Download the repository and install dependencies.

# Clone repository
git clone https://github.com/asta-nguyen/kamehadb.git
# Enter folder
cd kamehadb
# Install dependencies
pnpm install

2. Start dev databases

Bring up PostgreSQL, MySQL, MariaDB, and Redis containers.

# Start services
docker compose up -d

3. Default credentials

Use these values in the connection form.

EnginePortUserPasswordDatabase
PostgreSQL5432kamehakamehakamehadb
MySQL3306kamehakamehakamehadb
MariaDB3307kamehakamehakamehadb
Redis6379———

4. Run the app

Start sidecar and desktop app together.

# Run dev mode
pnpm dev
