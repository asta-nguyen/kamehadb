Features

KamehaDB combines a powerful SQL editor with AI-powered assistance to make database work faster and more intuitive.

AI AI-SQL Generation

Chat naturally with AI to generate, explain, and debug SQL queries. The AI has access to your database schema, so it knows your table structure, columns, and relationships. Supports OpenAI, Ollama (local/cloud), and 9Router.

AI Schema-Aware Context

AI automatically builds context from your database schema (CREATE TABLE statements, column types, foreign keys, indexes). No more guessing table names or column types.

CORE Multi-Engine Support

Connect to PostgreSQL, MySQL, SQLite, MongoDB, and Redis from a single application. Each engine is supported with native query capabilities.

CORE Schema Browser

Browse databases, schemas, tables, columns, and indexes with a tree-view navigator. See column types, nullable flags, defaults, and foreign key relationships.

CORE SQL Editor

Monaco-based editor with syntax highlighting, autocomplete, FK-aware JOIN suggestions, and execution with results grid.

VISUAL ER Diagrams

Auto-generated entity relationship graphs powered by ReactFlow. Visualize how tables connect via foreign keys. Zoom, pan, and explore relationships interactively.

CORE Connection URL Parser

Paste postgresql://, mysql://, or redis:// URIs to auto-fill connection fields. No more hunting for port numbers.

CORE Local-First Storage

All connection profiles and metadata stored locally via SQLite. Credentials encrypted at rest. No secrets sent to the cloud.
