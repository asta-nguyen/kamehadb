FAQ

Quick answers about setup, security, AI providers, and daily workflow in KamehaDB.

KamehaDB is a local-first desktop database GUI with built-in AI for PostgreSQL, MySQL, SQLite, MongoDB, and Redis.
The assistant uses schema context (tables, columns, constraints) so generated SQL is relevant to your selected database structure.
OpenAI-compatible providers are supported, including OpenAI, Ollama, and 9Router.
Connection metadata is local-first. If you choose cloud AI providers, prompt context is sent to that provider. Local Ollama keeps data on your machine.
Open an issue on the GitHub tracker with steps to reproduce and expected behavior.
