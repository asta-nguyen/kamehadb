Quick Setup

Get up and running in seconds.

bash 
# Install dependencies
pnpm install

# Start dev services (PostgreSQL, MySQL, MariaDB, Redis)
docker compose up -d

# Run both sidecar and desktop in dev mode
pnpm dev
